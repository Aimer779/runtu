# 润图 SoftShot

一个轻量的浏览器截图美化工具。导入截图后，为图片添加背景、留白、圆角和阴影，实时预览并导出 PNG，适合整理文档配图、产品截图和社交分享图片。

项目采用单文件 HTML，样式和脚本均内嵌，无需安装依赖、构建或配置后端。

## 快速开始

1. 下载本仓库，或通过 Git 克隆：

   ```powershell
   git clone https://github.com/Aimer779/runtu.git
   cd runtu
   ```

2. 双击 `runtu.html`，使用浏览器打开。
3. 选择图片、将图片拖入预览区域，或粘贴剪贴板中的图片。
4. 选择搭配并调整参数，然后点击「下载 PNG」或「复制」。

直接打开文件即可进行图片编辑和下载。复制图片受浏览器剪贴板权限限制；如果复制失败，可改用下载，或通过本地 HTTP 服务访问。

如果已安装 Python，可以在仓库目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

然后打开 <http://localhost:8000/runtu.html>。按 `Ctrl+C` 停止服务。Python 只用于这个可选的本地服务，不是应用运行依赖。

## 功能

| 功能 | 说明 |
| --- | --- |
| 图片导入 | 文件选择、拖放、剪贴板粘贴；图片格式以浏览器解码能力为准 |
| 内置搭配 | 默认、文档、社交、窗口、展陈，共 5 组 |
| 背景 | 多种渐变、自定义纯色、透明背景、自选背景图、基于原图的霜化背景 |
| 构图 | 调整外圈留白、内圈留白、圆角、阴影大小及浓度 |
| 画布 | 自适应、1:1、16:9、4:3、3:2；固定比例下有可用空间时可拖动图片位置 |
| 装饰 | 可切换窗口顶栏、细微噪点，并调整图片背景模糊程度 |
| 保存搭配 | 最多保存 12 组自定义搭配，可指定下次打开时的默认搭配 |
| 导出 | 1× / 2× PNG，支持透明背景，也可复制成图到剪贴板 |

导出尺寸根据原图、构图参数和倍率计算；任意一边超过 8000 像素时，会等比例缩小至该上限。提高导出倍率不会恢复原图中不存在的细节。

## 快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 粘贴图片 | `Ctrl+V` | `Cmd+V` |
| 下载 PNG | `Ctrl+S` | `Cmd+S` |
| 复制成图 | `Ctrl+C` | `Cmd+C` |
| 清除当前图片 | `Delete` | `Delete`（键位取决于键盘） |

下载、复制和清除需要先导入图片。在文本输入框中，复制及删除键保留文本编辑行为。「换一张」会清除当前图片，之后可以重新导入。

## 数据与网络

- 本地导入的图片通过浏览器对象 URL 和 Canvas 在本机处理，代码没有上传图片的接口。
- 页面会请求 Google Fonts 加载界面字体，因此并非完全无网络请求；字体不可用时使用系统字体回退。
- 参数、自定义搭配及默认搭配保存在当前浏览器的 `localStorage`，不会同步到其他浏览器或设备。清除网站数据会删除这些设置。
- 原图和自选背景图不写入持久存储，刷新后需要重新选择。自选背景图不可用时，背景会回到内置搭配。
- 界面中的「开机默认」指下次打开页面时采用的搭配，不会设置操作系统开机启动。
- 浏览器禁用本地存储或存储空间不足时，设置可能无法保存；使用 `file://` 打开时，本地存储及剪贴板行为也可能因浏览器而异。

## URL 参数

可通过查询参数设置初始效果，例如：

```text
runtu.html?look=window
runtu.html?bg=celadon&ratio=16%3A9&chrome=1
```

| 参数 | 支持的值 |
| --- | --- |
| `look` | `clean`、`doc`、`social`、`window`、`gallery` |
| `bg` | `haze`、`studio`、`xuan`、`celadon`、`seafog`、`champagne`、`lilac`、`dusk`、`night`、`inkstone`、`slate`、`matcha`、`solid`、`clear`、`photo`、`frost` |
| `ratio` | `auto`、`1:1`、`16:9`、`4:3`、`3:2` |
| `chrome` | `1` 开启窗口顶栏 |
| `demo` | 自动加载的图片地址；建议使用同源图片，跨域图片可能使 Canvas 无法导出 |

有效的 `look` 会覆盖该搭配包含的其他参数。`photo` 背景仍需手动选择本地图片；URL 不会携带本地图片内容。

## 项目结构与开发

```text
runtu/
├── runtu.html  # 页面结构、样式、Canvas 渲染与交互
└── README.md   # 使用和维护说明
```

技术栈为原生 HTML、CSS 和 JavaScript，使用 Canvas 2D、Clipboard API 和 localStorage。修改 `runtu.html` 后刷新浏览器即可查看结果，无需编译。

仓库目前没有自动化测试套件。修改渲染或交互逻辑后，建议手动检查图片导入、背景切换、固定比例拖动、搭配保存与重新打开、透明 PNG 下载和剪贴板复制。大图、2× 导出及模糊效果可能增加内存和渲染开销，实际表现取决于设备与浏览器。
